# Политика приватности Rivus

Rivus — локальное приложение. У проекта нет аналитики, аккаунтов, облачной синхронизации и серверов, которые собирают данные.

## Что не отправляется

- история посещений, поисковые запросы, закладки;
- пароли и содержимое форм;
- идентификаторы устройства, crash-отчёты, usage-статистика;
- содержимое страниц (кроме обычных запросов к самим сайтам).

## Единственный внешний запрос проекта

Проверка обновлений: `https://api.github.com/repos/227375488489/rivus/releases/latest`.

Она выполняется не чаще раза в сутки, только если включён пункт «Проверять обновления». Передаётся стандартный User-Agent `Rivus/<версия>`; никаких идентификаторов. Загрузка обновления идёт с `github.com` и проверяется по SHA-256. Проверку можно отключить в настройках.

## Что хранится на диске

Каталог `%LOCALAPPDATA%\Rivus`:

| Файл | Содержимое |
|---|---|
| `settings.json` | настройки, темы, правила щита |
| `history.jsonl` | история (можно отключить очисткой/политикой) |
| `bookmarks.json` | закладки |
| `session.json` | открытые вкладки для восстановления |
| `cookies.json` | постоянные cookie собственного движка |
| `vault.bin` | пароли, ChaCha20-Poly1305; ключ в Windows Credential Manager |
| `webviews\<контейнер>\` | профили WebView2: cookie, кэш, localStorage, IndexedDB |
| `filters\*.txt` | пользовательские списки блокировки |

Всё удаляется в «Настройки → Приватность → Стереть данные» или вручную.

## Cookie и контейнеры

- Собственный движок: cookie привязаны к контейнеру; сторонние cookie блокируются по умолчанию; session-cookie не пишутся на диск.
- Режим совместимости: каждый контейнер — отдельный профиль WebView2, поэтому сайты из разных контейнеров не видят хранилище друг друга.
- Одноразовый контейнер использует incognito-профиль; каталог удаляется при выходе.
- Третьи стороны внутри одного профиля контролируются Chromium/WebView2. Rivus не перехватывает TLS и не может гарантировать поведение, отличное от Chromium.

## Блокировка рекламы и трекеров

Запросы WebView2 идут через локальный HTTP-прокси на `127.0.0.1` со случайным портом. Прокси:

- видит только хост и порт из `CONNECT` (без расшифровки трафика);
- сверяет хост со встроенными и пользовательскими списками;
- возвращает `403` для рекламы, трекеров и майнеров;
- не пишет журналы на диск.

Ограничения: блокировка по хосту, а не по пути; CNAME-клоакинг не раскрывается; сайт может определить сам факт использования прокси.

## Fingerprinting

В режиме совместимости Rivus выставляет `DNT: 1`, `Sec-GPC: 1`, единый User-Agent Chrome и отключает prefetch. Шум для Canvas/WebGL/AudioContext не добавляется, потому что это ломает сайты и не гарантирует анонимность против современных методов.

В режиме чтения JavaScript не выполняется вообще: поверхности для canvas/WebGL/AudioContext fingerprinting отсутствуют.

## Ваши права

Все данные принадлежат вам и лежат на вашем компьютере. Для удаления достаточно стереть `%LOCALAPPDATA%\Rivus` после закрытия браузера.
